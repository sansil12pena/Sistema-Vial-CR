# Sistema-Vial-CR
Se comenta cada paso para mejor manejo de la informacion, y poder trabajarlo mas sencillo en la parte del desarrollo final, se investigaron 2 herramientas no vistas, ya que para cumplir con el objetivo del proyecto eran esenciales
## Descripcion

Sistema web para consultar informacion sobre incidentes viales en Costa Rica.

## Funcionalidades

- Consulta de incidentes viales.
- Visualizacion de incidentes en un mapa.
- Consulta del estado de carreteras.
- Rutas alternativas.
- Formulario de reportes viales.
- Alertas viales.
- Dashboard con estadisticas.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Leaflet
- OpenStreetMap
